React Frontend Developer

Engineering Remote Full-time Competitive salary
Apply for this role

About the role

We're looking for a React Frontend Developer to craft fast, accessible interfaces for products used by 800+ businesses worldwide. You'll turn designs into pixel-perfect, responsive UIs and collaborate closely with our backend and design teams. This is a remote role with flexible hours.

What you'll do

  • Build responsive, accessible UIs in React
  • Turn Figma designs into pixel-perfect components
  • Integrate REST APIs and manage app state
  • Write reusable, well-tested components
  • Optimize front-end performance
  • Collaborate with design and backend teams

What we're looking for

  • 3+ years of professional React experience
  • Strong HTML, CSS, and modern JavaScript
  • Experience with state management (Redux/Zustand)
  • A sharp eye for detail and clean UI
  • Familiarity with Git and CI/CD
  • Clear communication

Nice to have

  • Experience with Next.js or TypeScript
  • Knowledge of testing (Jest/RTL)
  • Open-source contributions
