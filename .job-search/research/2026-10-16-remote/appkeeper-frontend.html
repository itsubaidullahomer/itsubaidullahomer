Frontend Developer

Craft polished, performant interfaces for complex data applications.

About the Role

We're looking for a Frontend Developer to build beautiful, high-performance interfaces for our SaaS products. You'll work on complex dashboards, real-time data visualizations, and design systems that serve as the foundation for multiple products.

Our frontends handle large datasets, live WebSocket streams, and intricate user workflows. You'll collaborate directly with backend engineers and designers to deliver interfaces that are both powerful and intuitive.

What You'll Do

  • Build and maintain complex SaaS dashboards with React and TypeScript
  • Create reusable component libraries and design systems
  • Implement real-time data visualizations using charting libraries
  • Integrate with REST APIs and WebSocket connections
  • Optimize frontend performance: bundle size, rendering, lazy loading
  • Write comprehensive tests: unit, integration, and E2E
  • Collaborate with UX designers on interaction patterns and prototypes
  • Implement responsive layouts and cross-browser compatibility
  • Participate in code reviews and architectural decisions

Requirements

  • 3+ years of professional experience with React and TypeScript
  • Experience building and maintaining design systems or component libraries
  • Data visualization experience (D3.js, Recharts, ECharts, or similar)
  • Strong CSS skills: Grid, Flexbox, animations, responsive design
  • REST API integration and state management (React Query, Zustand, or Redux)
  • Testing: Jest, React Testing Library, Cypress or Playwright
  • Build tools: Vite, Webpack, or similar bundlers
  • Git workflow and code review experience

Nice to Have

  • Experience with Vue 3 and its ecosystem
  • WebSocket and real-time data handling
  • Accessibility (WCAG) expertise
  • Experience with Storybook for component documentation
  • Familiarity with Figma and design-to-code workflows
  • Knowledge of Next.js or Nuxt for SSR applications

Tech Stack

React TypeScript Vue 3 Vite Tailwind CSS D3.js Recharts React Query Playwright Storybook Figma
