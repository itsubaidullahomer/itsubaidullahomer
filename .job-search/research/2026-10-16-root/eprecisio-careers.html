Senior MERN Full-Stack Engineer

Full-time · On-siteFaisalabad, PK3+ years
Apply now

Senior MERN engineer for an in-house music and audio SaaS platform that real artists and customers depend on every day. End-to-end SaaS delivery and team leadership. You own outcomes, not tickets. You will work across React (TypeScript), Node.js / Express, MongoDB, with Auth0, Stripe, AWS, and Socket.io.

What you will do

  • Take features from discovery and design through implementation, testing, deployment, and post-release monitoring. You own the outcome, not just the ticket
  • Set direction on architecture and code quality, run reviews that level up the team, and mentor mid and junior engineers
  • Build responsive React front-ends (TypeScript) and robust Node / Express APIs backed by MongoDB, with real-time features over Socket.io
  • Own Stripe subscription and billing flows, Auth0-based auth, and AWS-backed media and messaging (S3, SQS)
  • Own the health of what you ship: performance, observability, and on-call response when something breaks

Must have

  • 3+ years building production web applications with the MERN stack (MongoDB, Express, React, Node.js)
  • Demonstrated ownership of end-to-end SaaS delivery. You have carried features (or whole products) from concept to live customers
  • Team-leadership mindset: mentoring, code review, and raising standards come naturally, whether or not you have held a formal lead title
  • Strong JavaScript and TypeScript fundamentals, with solid React (hooks, Redux / Redux Toolkit) and Node / Express experience
  • Hands-on with MongoDB and Mongoose data modelling, REST API design, and authentication (JWT / Auth0)
  • Comfort with the full delivery lifecycle: Jest testing, CI / CD, Docker, and debugging in production

Nice to have

  • Stripe subscription and billing integration in production
  • AWS services in production (S3, SQS) and Docker-based deployment
  • Real-time and event-driven features with Socket.io or similar
  • Music, audio, media-streaming, or other content-heavy SaaS domains
  • Multi-tenant SaaS architecture, RBAC and permissions, prior experience leading a small team or owning a product area
