# Decisions

- This checkout is the GitHub profile repository, not the Next.js portfolio described in the brief. Build the requested portfolio in this checkout, preserving README, assets, data and the daily profile workflow. Its command moves to `npm run profile:build`; the existing workflow calls the script directly and is unaffected.
- The live portfolio is the content source of truth. On 10 October 2026 its sitemap exposed nine case studies and two articles; preserve every URL, including `/work/insight-x` (Illume) and `/work/ai-humanizer` (Viloi). Keep Writing because real posts exist on the live source even though this checkout lacked them.
- Use the live site's current 20k+ audience, not the profile's older 17k figure. Preserve historical figures inside dated articles.
- Keep Now: current projects and actual public contribution data add context. Never generate fake contributions when GitHub is unavailable. Retain the source content's update date rather than imply newly verified activity.
- Pricing remains null with explicit TODOs in content; visitors see “Scope first, quote second” until the owner supplies prices. No invented commercial commitments.
- Missing credentials are not a reason to leave a broken interaction: the avatar opens an honest booking/email fallback; paid providers fail closed without distributed rate limiting.
- No frontend-design or browser skill is installed. Use the available browser automation, official API docs, TypeScript and responsive screenshot review as equivalents.
- Verified `@decartai/sdk` currently exposes Lucy video models, not `live_avatar`, and no documented PCM/audio-chunk avatar API. Do not invent SDK methods or substitute a camera-restyling service. `/api/avatar/decart-token` fails safely to the portrait renderer without minting billable tokens. Gemini voice and text remain implemented. Animated facial rendering is a documented vendor blocker.
- Gemini native-audio model `gemini-3.8-live` and ephemeral token constraints were verified against Google’s current Live documentation and installed SDK declarations. The model is configurable. Token expiry rejects further messages after 180 seconds; the browser also ends at that bound and after 20 seconds of silence.
- Rate limits fail closed without Upstash. Atomic daily counters enforce three sessions per IP and a configurable global count. The browser receives no permanent provider secrets. Text history is server-owned, expires with the session, and is limited to 12 bounded responses. Only Vercel’s overwritten IP header is trusted; other hosts share a conservative bucket.
- Playground ships three local, explicit simulations: a configurable resilient stream, an interruptible voice call (optional browser speech), and an explorable Tututor request trace. Prefer an accurate architecture tool to a mind map that pretends templated output came from AI. No experiment needs API keys or incurs usage.
- The full GitHub contribution calendar uses the authenticated official GraphQL API with daily revalidation. Without a token, use the official public-events API, honestly labeled as a partial recent-activity window. Never fill a year with invented contribution counts.
- The final mobile hero uses only the portrait device. Removing decorative rear screenshots below 540px improves focus, avoids unnecessary visual weight and improves mobile LCP. Desktop keeps the requested layered product depth.
- Scroll reveals progressively enhance already-visible HTML using one-shot observers. Disabling JavaScript cannot hide the content. Reduced motion keeps fades and disables movement, blur, parallax and looping animations.
- The accessibility pass fixed whitespace in Radix tab values (invalid IDREFs), raised small-label contrast and hid copy-button glyphs from accessible names. The request-origin check also handles Next’s localhost normalization using the actual HTTP Host, without trusting arbitrary forwarded-host headers.

- On 11 October, the owner requested a ChatGPT account connection so visitors can experience the work with their own eligible plan allowance. Public AI entry points now open the ChatGPT text demo. The earlier Gemini voice implementation stays in the repository but is not mounted by these entry points; no fallback charges the owner.
- Hosted ChatGPT access is gated by the approved client, explicitly approved plan scope, Redis and encryption configuration. Do not use the local/open-source dynamic registration flow as a workaround for hosted approval. This implementation needs a live partner-account verification before activation.
- Keep the connection short-lived (15 minutes), with no offline access or stored refresh token. Use the visitor’s actual model catalog, disclose plan usage, preserve unfinished drafts and keep human contact available without a sign-in.
- The owner requested selective color and more character on 11 October. Keep the white layout and monochrome portraits; reveal original project colors on hover or keyboard focus, and show them immediately on touch devices and small screens. Expanded project images remain in color. Service illustrations use softly colored CSS surfaces, bevels and shadows, with movement only on hover when reduced motion is not requested; no additional rendering library or image download is needed.
